# @coding-tree-io/boxnow-core

Internal shared contracts and validation helpers for the BOX NOW Toolkit.

This package is private to the monorepo. It is not the supported end-user import
path. Consumers should import from one of the public packages:

- `@coding-tree-io/boxnow`
- `@coding-tree-io/boxnow-widget`
- `@coding-tree-io/astro-boxnow`

Public packages curate the contracts they expose from this internal package.
