# @coding-tree-io/astro-boxnow

Astro Integration for BOX NOW Locker Selection.

## Planned Scope

- Validate browser-safe integration options.
- Compose `@coding-tree-io/boxnow-widget`.
- Provide `BoxNowLockerPicker.astro`.
- Document selected and cleared DOM event contracts.
- Work in static and SSR Astro projects.

## Non-Goals

- No checkout routes.
- No payment routes.
- No order persistence or fulfillment workflow.
- No Server Credential access from browser-facing config.
- No package exports until the implementation phase creates real entry points.

See `.planning/public-api-sketch.md` for the Phase 01 contract skeleton.
